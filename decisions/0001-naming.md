# ADR 0001 — 项目正式定名为 BluePrinter

**Date**: 2026-05-25
**Status**: Accepted
**Authors**: 杨镜池

---

## 背景

项目早期使用代号 **PanoSpec / 全景译**，强调 360° 全景输出 + 翻译外行需求的双关。

讨论过程中识别出 PanoSpec 的几个问题：
- "Spec" 在中文受众理解度低
- 中英对应不够顺滑
- 偏工具型描述，缺品牌气质
- 没体现"建筑+产品双覆盖"和"小工作室定位"

候选名字按风格分组讨论过 13 个选项（工具型 / 品牌型 / 沟通型 / 场景型）。

## 决定

正式定名为 **BluePrinter**。

## 理由

1. **Blueprint = 蓝图**，行业通用词，设计/工程/建筑/产品都用，覆盖双线
2. **-er 后缀**，把工具拟人化（"做蓝图的"），暗合"为客户出方案的助手"
3. **Print** 字面有"打印输出"含义，呼应"一键 PDF 方案书"
4. 英文好记好拼，中文不必硬翻（保持 BluePrinter 即可，必要时用"蓝图智造"）
5. 域名/商标可获得性高（待确认）

## 影响

- 所有文档统一用 BluePrinter
- GitHub repo 命名：`blueprinter`
- 文档中保留"项目原代号 PanoSpec"作为历史脉络
- 后续 logo / 视觉设计围绕"蓝图"语言展开

## 备选方案及未选原因

| 候选 | 未选原因 |
|---|---|
| PanoSpec / 全景译 | "Spec" 中文受众陌生，太工具感 |
| 出图 / Outline | 太行业黑话，品牌感弱 |
| 设感 / SenseDesign | 需要解释才懂，传播阻力大 |
| 图坊 / Atelier | 太保守，缺锐度 |
| Vesta | 罗马家神，仅覆盖家装维度，不覆盖产品 |
