# 一、现状与问题

**核心痛点**：全国数万家 4-10 人小设计/装修工作室被夹在中间——买不起酷家乐企业版，没人手用 SketchUp+V-Ray，又必须给客户出像样的提案。

**数据支撑**：

- 每个客户提案要 3-5 天人工搭建，平均改稿 5-8 轮才能签字
- 现有 AI 工具被骂"光打不好、AI 味重、prompt 不听话、学习曲线陡"
- 工作室常常空间 + 软装 + 产品定制混做，竞品全是单领域工具，统一交付难

**场景化共鸣**：张老板 5 人家装工作室，月均接 8 单，光做提案就要 30 天，签字率只有 30%。如果有 AI 替他出"客户能直接签字的提案"，省下的人工就是利润。

---

# 二、解决方式

**一句话**：用多 Agent 协同 + 物理引擎，把外行需求 90 秒翻译成 360° 专业方案图。

**核心功能**：

- **自然语言输入**："120 平日式三居，老人和孩子住，预算 25 万"
- **六大 Agent 并行约束（前端可视化对话流，即看即懂）**：需求解析 / 法规合规 / 材料结构 / 物理验证 / 风格美学 / 成本估算
- **输出一套"外行看得懂、工程师能接手"的可沟通方案**：4 张多视角效果图 + 1-3 张可拖拽 360° 全景图 + 平面图标注 + 合规清单 + 材料 BOM + 一键 PDF 方案书

---

# 三、我们如何构建的

**技术路径**：Agent 约束层 → Blender 生成层 → 自动化决策智能层 → 沟通交付层。

**架构分层**：

- **Agent 约束**：LangGraph 编排 6 Agent（需求/材料/物理/风格/成本/合规）+ Claude 4.7 + RAG
- **Blender 生成**：bpy 程序化建房放家具，干涉/采光/承重粗校
- **决策智能（核心护城河）**：HDRI 智能选 + 三点布光 + 摄像机调度 + 后期 LUT + 摆放扰动，避"CG 味"
- **渲染交付**：Cycles 离线 4K + Pannellum 网页 360° + WeasyPrint 一键 PDF 方案书

**关键突破**：把"自动化光照/构图/后期"这套设计师隐性知识工程化，让 AI 出图被评"和设计公司一个水准"。

---

# 四、我们所引以为豪的是

**核心定位**：**AI 设计赛道都在比功能，我们只比一件事——把"看着像 AI"变成"看着像设计公司"。**

**四条护城河**：

1. **自动化决策智能层**（HDRI / 三点布光 / 构图 / LUT / 摆放扰动）
2. **建筑 + 产品双覆盖**，竞品全是单领域工具，小工作室真需要统一交付
3. **交付一份"客户能签字的 PDF 方案书"**，不是图片，也不是工具
4. **端到端傻瓜化，零学习成本**，让工作室老板娘也能用

**影响力**：替小工作室省 80% 提案时间，签字率从 30% 拉到 60%。

3. **执行速度本身就是护城河**——6 个月内拿下 100 家小工作室 + 沉淀模板库
