# BluePrinter · 全景译  ——  产品需求文档 (PRD v0.1)

> AI 多智能体 × 物理引擎，把每个想法变成可沟通的 360° 专业方案

---

## 0. 一句话定义

**BluePrinter 是给 4-10 人小设计工作室的 AI 方案生成助手 —— 一句话出客户能签字的完整方案包，建筑空间和工业产品都能做。**

用户用自然语言描述需求，多 Agent 协同决策"用什么资产 / 怎么布光 / 摆在哪里 / 怎么构图"，由 Blender 程序化建模 + Cycles 离线渲染输出 360° 全景图 + 多视角效果图 + 工程标注 + 一键 PDF 方案书。

**slogan**：AI 设计赛道都在比功能，我们只比一件事 —— 把"看着像 AI"变成"看着像设计公司"。

- 不是 AI 画图工具（不是 Midjourney/Vizcom）
- 不是 AI CAD（不是 Zoo.dev/Autodesk）
- 不是设计师工作台（不是酷家乐/Homestyler）
- **是"小工作室的方案生成助手"**：替工作室老板把"客户需求 → 可签字提案"这段 80% 时间砍掉

## 1. 问题与机会

### 1.1 行业痛点（B 端）

| 行业 | 痛点 | 现状成本 |
|---|---|---|
| 家装设计 | 客户看不懂图纸，平均 5-8 轮改稿 | 每方案 2-3 周、2-5 万元设计费 |
| 工业产品设计 | 草图→工程脱节，60% 初稿不可制造 | 每轮 1-2 周 |
| 小型商业空间 | 法规合规靠人工查，错漏频发 | 漏一条罚款数万 |
| 建材/家具销售 | 客户难以可视化"装进我家是什么样" | 转化率 < 5% |

### 1.2 用户痛点（C 端）

- "我想要个温馨的家"——这句话设计师听了无数次，但无法立即可视化
- 客户花钱才看到效果图，看完不满意再改要加钱
- 装修/购房前完全靠想象 + 样板间，决策成本高、后悔率高

### 1.3 市场规模

- 中国家装市场：**4 万亿/年**（住建部数据），设计服务费 **300 亿+/年**
- 中国工业设计服务市场：**3000 亿+/年**
- 全球 AEC（建筑/工程/施工）AI 市场：**2025 年 90 亿美元，2030 年预计 280 亿美元**
- AI in Industrial Design：**2024 年 15 亿美元，CAGR 28%**

## 2. 目标用户

### 2.1 P0 用户：4-10 人小设计工作室

**为什么是他们**：
- ❌ 没钱用酷家乐企业版（年费几万起）
- ❌ 没人手专门搞 SketchUp + V-Ray + Photoshop 出提案
- ❌ 又必须给客户出"像样的提案"才能签单
- ✅ 全国数万家、决策链短、付费意愿 999-2999/月
- ✅ 业务边界天然横跨"空间 + 软装 + 产品定制"，BluePrinter 双覆盖正中下怀

**典型画像**：
- 张老板，杭州，5 人家装工作室，年营收 300 万
- 每个客户提案要 3-5 天，主要时间花在"客户讲不清 → 反复改方案"
- 用 BluePrinter：1 小时出 3 套方案给客户选，客户签字率从 30% 提升到 60%

### 2.2 P1 用户（半年后扩展）

- **独立设计师 / 自由职业者**（299-999/月）

## 3. 核心使用场景

### 3.1 场景 A：业主自助装修方案（C 端 demo 场景）

**用户**：李女士，30 岁，刚买 120m² 三居，准备装修
1. 打开网页/小程序，对话："120 平三室两厅，老人和孩子住，喜欢日式自然风，预算 25 万"
2. 上传户型图（CAD/手绘照片均可）或选择系统模板
3. 等待 2-3 分钟（前端展示 6 个 Agent 实时协同对话流）
4. 收到方案：
   - 4 张效果图（玄关/客厅/主卧/儿童房）
   - 3 张 360° 全景（客厅/餐厅/儿童房，鼠标拖动看一圈）
   - 平面图 + 尺寸标注
   - 法规合规清单（防火/采光/老幼适配/无障碍）
   - 材料 BOM + 分项预算
   - PDF 方案书（可打印）
5. 局部修改："厨房改开放式" → 防火 Agent 弹窗"需加排烟+报警" → 自动调整 → 重渲
6. 满意 → 一键分享给设计师 / 装修公司

### 3.2 场景 B：工业产品概念设计（产品扩展场景）

**用户**：王工，小家电创业团队产品经理
1. 输入："设计一台桌面咖啡机，500ml，简约风，目标售价 599"
2. 等待 2 分钟
3. 收到：
   - 4-6 张产品效果图（前/侧/顶/45° 等）
   - 360° 转盘视图（可旋转看一圈）
   - 三视图 + 尺寸标注
   - 材料/工艺说明（ABS 注塑/铝合金 CNC）
   - 简易爆炸图（说明组件）
   - 成本估算 + 关键供应商建议
4. 调整："换金属拉丝外壳" → 材质 Agent 调整 + 成本 Agent 警告"+85 元"
5. 导出 → 拿去找模具厂、找设计公司做工程化

### 3.3 场景 C：小商业空间方案（B 端拓展场景）

咖啡馆/便利店/工作室开业方案：空间布局 + 消防/卫生合规 + 装修预算 + 设备清单。

## 4. 核心功能（MVP 范围）

### 4.1 必做（Hackathon 48h）

| 功能 | 说明 | 验收 |
|---|---|---|
| 自然语言需求输入 | 文字 + 可选语音 | 支持中文长文本 |
| 多 Agent 编排 | 6 个 Agent 并行：需求/法规/材料/物理/风格/成本 | 前端可视化对话流 |
| 法规合规检查 | RAG GB50096/50016 等核心 20 条 | 命中违规自动标红+建议 |
| Blender 程序化建模 | 按 spec 自动建房间/家具/材质 | 单方案 < 60s |
| Cycles 离线渲染 | 4K 多视角 + equirectangular 全景 | 4 张图 < 3min |
| Pannellum 全景查看器 | 网页 360° 漫游 + 热点标注 | 移动端可用 |
| PDF 方案书生成 | 一键合成所有内容 | A4 8-12 页 |

### 4.2 应做（4 周内）

- 户型图识别（CAD/手绘照片 → 结构化 JSON）
- 局部修改对话（"沙发换深绿"自动重渲该视角）
- 工业产品场景接入
- 用户账户 + 方案历史
- 移动端响应式

### 4.3 可选（3 月内）

- 真实材料库接入（淘宝/京东/米思米 API）
- 与装修公司合作的方案派单
- AR 实景预览（手机摄像头看家具放进去）
- 出海版（英文/法规库本地化）

### 4.4 不做（明确边界）

- ❌ 替代施工图（不出 CAD DWG，只出可参考 DXF）
- ❌ 真实有限元结构分析（只做几何/材料粗校）
- ❌ 实时多人协作编辑（V1 单用户）
- ❌ 完整 BIM（只做装修级，不做建筑设计级）

## 6. 技术架构

### 6.1 后端

```
[用户输入]
   ↓
[FastAPI + WebSocket]  ← 推送 Agent 工作流给前端
   ↓
[LangGraph Agent 编排器]
   ├ 需求解析 Agent (Claude Sonnet)
   ├ 法规合规 Agent (Claude + RAG ChromaDB)
   ├ 材料/结构 Agent (规则 + LLM)
   ├ 物理验证 Agent (Blender bpy)
   ├ 风格/美学 Agent (Claude)
   └ 成本估算 Agent (规则 + 价格库)
   ↓
[Supervisor Agent]  ← 冲突仲裁
   ↓
[统一 Spec JSON]
   ↓
[Blender Worker (Docker)]
   ├ bpy 程序化建模
   ├ 物理预验证 (Rigid Body)
   ├ Cycles 离线渲染 (4 张 + 1 全景)
   └ 输出 PNG + equirectangular JPG + GLB
   ↓
[输出 CDN] → 前端展示
```

### 6.2 前端

- Next.js 14 + React 18
- 3D 全景：**Pannellum** (50KB, 零依赖)
- 状态管理：Zustand
- 实时：Socket.io / SSE
- UI：Tailwind + shadcn/ui
- PDF 在线预览：react-pdf

### 6.3 关键组件选型

| 层 | 选型 | 替代方案 |
|---|---|---|
| LLM | Claude 4.7 Sonnet（主）+ GPT-4o（备）| Claude Haiku |
| Agent 框架 | LangGraph / Claude Agent SDK | CrewAI / AutoGen |
| 3D 引擎 | **Blender 4.x + bpy** | 无替代（Maya 贵、Houdini 重）|
| 渲染 | Cycles（终图）+ EEVEE（预览）| —— |
| 物理 | Blender Rigid Body | Bullet / Rapier |
| 全景查看 | **Pannellum** | Marzipano / Photo Sphere Viewer |
| 法规 RAG | ChromaDB + LangChain | Qdrant |
| 资产库 | PolyHaven (HDRI/材质) + BlenderKit (家具) | Sketchfab |
| PDF 生成 | WeasyPrint | ReportLab |
| 部署 | Docker + GPU 云（如阿里 RTX A10）| 本地 RTX 4090 |

### 6.4 性能目标

- 单方案 P50 生成耗时：**90s**（家装）/ **60s**（产品）
- 单方案 P95：**180s**
- 渲染分辨率：4K (3840×2160) 多视角，4K×2K equirectangular 全景
- Blender 单台 GPU 并发：4 个方案队列
- 月活 1000 用户的服务器成本：**< 2 万元**

## 7. 差异化与竞争

### 7.1 竞品全景（按真实威胁等级评估，已经 deep dive 核查过）

| 类别 | 代表产品 | 已覆盖能力 | 真实短板（来自用户实测/测评）| 威胁 |
|---|---|---|---|---|
| 家装/空间云设计 | 酷家乐 / Coohom / Homestyler / Planner 5D | AI 文字布局、4K 渲染、360° 全景、BOM 报价、施工图 | 专业设计师评："**出图快但光打不好、写实感不够、看起来像模型**"；学习曲线陡；产品库限制定制；模板感强 | 🚨🚨 |
| AI 室内/建筑渲染 | mnml.ai / Reviz / Fenestra / ReimagineHome / RoomGPT | Sketch/3D model → photoreal 渲染、对话式编辑、多软件集成 | mnml 重大问题：**prompt adherence 差**（输入和输出对不上）、独立社区几乎不存在、价格半年涨 50%；都是 2D 图像编辑或单图渲染，**无 360 全景 + BOM + 方案包闭环** | 🚨 |
| 建筑生成式 / 规划 | Finch / Maket / TestFit | 平面布局、面积计算、code compliance、BIM 几何、可行性 | 偏 AEC 专业工具，**不做高质量静态渲染交付包**；不做产品；交付物是数据/几何，不是"客户能签字的提案" | 🚨 |
| 工业设计 AI 渲染 | Vizcom / Depix / Industrial Render AI / PromeAI | Sketch-to-render、多视角、CMF、材质风格；Depix 有 Design Lab 编排 + Product Vision 文字概念 | Depix 实测："**Best when you already have a sketch/CAD/clay model**"，偏 refinement 不是真"文字到方案"；学习曲线陡；**Vizcom 无 360/BOM/PDF**；Industrial Render AI 单图渲染 | 🚨🚨 |
| 专业渲染/展示 | KeyShot / Blender / Marmoset / Sketchfab | 高质量渲染、转盘动画、3D viewer | 输入要求已有 3D 模型，**不解决从文字到方案**；不是自动设计系统 | 🚨 |
| 通用 AIGC / 3D 生成 | Midjourney / Krea / Meshy / Tripo / Luma | 快速生成图像或 3D asset | 不懂工业方案结构；多视角一致性、尺寸、标注、BOM 都弱 | 🚨 |

### 7.2 行业**共同失败模式**——这是真机会

deep dive 完所有竞品后，发现整个 AI 设计赛道都踩同一组坑：

| 失败模式 | 谁踩了 |
|---|---|
| ❌ **AI 味/CG 味**（"光打不好"、"generic"、"render-like"）| 酷家乐、Homestyler、mnml 全部被骂 |
| ❌ **Prompt 不听话** | mnml 最严重，其他多少都有 |
| ❌ **学习曲线陡** | Coohom、Homestyler、Depix 都被吐槽 |
| ❌ **工具碎片化、不是端到端方案** | 几乎所有竞品都是"工具集"而非"交付物" |
| ❌ **单领域**（要么空间要么产品）| 没人统一做 |

**翻译**：AI 设计赛道在 2026 年仍是**"功能演示阶段"，没有进入"可交付生产阶段"**。

### 7.3 你能赢的 4 条护城河（已剔除"法学/合规"等伪护城河）

#### 1. **"自动化决策智能层"** ——核心技术护城河

**酷家乐的"光打不好"本质是 CG 味，不是 AI 味**。它也是 3D 引擎（不是扩散模型），但自动化光照不够智能 → 出来都长一个样。Blender 帮你避开"AI 味"，但避不开"CG 味"。

你的真竞争是 8 个自动化决策维度，做不好用什么引擎都白搭：

| 决策层 | 酷家乐水平 | 你要做到的 |
|---|---|---|
| HDRI 环境贴图选择 | 几个固定预设 | 按场景类型 + 时段 + 风格 Agent 智能选 |
| 三点布光 | 默认顶光 | 主+辅+轮廓光强度色温随风格变 |
| 摄像机角度 | 用户手转 | 黄金构图自动多视角 |
| 材质参数 | 库里固定 | LLM 微调 roughness/IOR/anisotropy |
| 物品摆放"生活感" | 完美对齐 | 加 ±2° 旋转、±3cm 噪声 |
| 后期合成 | 几乎没有 | 自动 LUT + 色调 + 轻景深 + vignette |
| 风格 LUT | 无 | 日式/北欧/工业风各 1 个 .cube |
| 叙事性构图 | 无 | Agent 决定"突出哪个家具" |

**这 8 层全做到 = 出图被评"和设计公司一个水准"，不是"AI 出的"。这才是真护城河。**

#### 2. **"建筑 + 产品"双覆盖**——竞品空白区

| 竞品 | 建筑 | 产品 |
|---|---|---|
| 酷家乐 | ✅✅ | ⚠（电商棚拍，不是核心） |
| Coohom / Homestyler / Planner 5D | ✅ | ❌ |
| Depix.ai | ❌ | ✅✅ |
| Vizcom / Industrial Render | ❌ | ✅ |
| mnml / Reviz / Fenestra | ✅ | ❌ |
| Maket / Finch / TestFit | ⚠（户型/平面）| ❌ |
| **BluePrinter** | **✅** | **✅** |

**小工作室常常空间+软装+产品定制混做，统一工具 = 真留存。**

#### 3. **"完整方案书交付物"**——竞品都给工具，没人给交付

竞品输出：图片 / 模型 / 渲染 / 数据
BluePrinter 输出：**装修公司能直接发给业主签字的 PDF 提案**（封面+效果图+360 全景链接+平面图+BOM+预算+条款）

这是 B 端工作室真正缺的东西，单点工具替代不了。

#### 4. **"端到端傻瓜"**——零学习曲线

酷家乐/Homestyler 的"专业软件感"挡住了 80% 小工作室。你要做到：
- 老板娘也能用
- 一句话给出 3 套方案给客户选
- 不让用户调参数 / 选模板 / 写 prompt 工程

### 7.4 **真正的风险**（不是现有竞品）

| 风险 | 真实严重度 | 为什么 |
|---|---|---|
| 别的创业团队也想到同样思路 | **高** | 这是个明显机会，6 个月内会有人冒出来 |
| LLM 原生支持 3D 输出（Gemini/Claude 长期） | **中-高** | 长期可能架空"多 Agent + 自动化"层 |
| 酷家乐补强 AI 质量 + 推个人版 | 中 | 大厂有资源但转身慢 |
| Depix 进入建筑赛道 | 中 | 他们融了钱，技术能扩 |

**结论**：**护城河不靠"我们做了什么"，靠"我们多快做透自动化决策层 + 多快锁定小工作室客群"。**速度是真护城河。
