## 1. 为什么必须有资产库

会议共识（2026-05-25 团队评审）：

> "设计师也是素材库搭起来的，不是从零一个一个搭起来。AI 直接生成 Blender 几何 → 形状很扭曲，质量根本不够看。"

→ **BluePrinter 的"AI 建模"在工程上等于 "LLM 选 + 组合预制 GLB / 应用预制纹理"**，不是 LLM 从零生成几何。
→ 资产库的**覆盖率**和**风格质量**直接决定我们的出图天花板。

---

## 2. 两个起步源（已锁定）

| 源 | 主要内容 | 协议 | 集成方式 | 我们的用法 |
|---|---|---|---|---|
| **[PolyHaven](https://polyhaven.com/textures)** | 4K/8K 纹理（textures） + HDRI 环境贴图 + 部分模型 | **CC0**（完全自由，无需署名）| 直接下载 / Blender 官方插件 | 主要走纹理 + HDRI |
| **[BlenderKit](https://www.blenderkit.com/?query=category_subtree:model)** | 海量 GLB / blend 模型库（家具、植物、装饰、人物）| 免费层 + 订阅层（~$10/月专业版）| Blender 内置插件直接拖拽 / API 下载 | 主要走 model |

**两者分工**：PolyHaven 包墙面/地板/木材/金属/HDRI 这层"材质 + 环境"；BlenderKit 包沙发/桌椅/灯具/植物这层"实体物件"。组合起来约 **覆盖 70% 西式家装场景**。

---

## 3. 协议合规要点

- **PolyHaven CC0**：商用、修改、再分发全部允许，无需署名。**最干净的选项**。
- **BlenderKit**：
  - **免费层资产**：CC-BY 或更宽松，可商用但通常要署名
  - **订阅层（Full Plan）**：Royalty Free，可商用无需署名
  - **必须验证每个资产的具体协议**（BlenderKit 网页上每个资产标记不同）
  - **黑客松 demo 阶段**：使用免费层 + 在 demo 末尾署名即可；正式产品需统一买订阅或筛选只用 CC0/Royalty Free 资产

⚠️ **不允许的操作**：把 BlenderKit 付费资产**打包进我们的开源仓库**（即使我们买了订阅）。

---

## 4. 还没解决的（必须自建或外采）

| 缺口 | 严重程度 | 备选 |
|---|---|---|
| **中式 / 日式家具**（屏风、榻榻米、官帽椅、案几）| 🔴 高，PolyHaven 几乎为零，BlenderKit 稀疏 | 自建 30 件起步 / Sketchfab 付费 / 国内 3d66.com |
| **小型工业产品**（个护、消费电子、小家电）| 🔴 高，资产库基本不覆盖 | 几乎只能自建 |
| **中式室内装饰**（青花瓷、字画、灯笼、漆器）| 🟡 中 | 自建 + Sketchfab |
| **西式现代家装**（北欧、极简、工业风）| 🟢 低 | PolyHaven + BlenderKit 已够用 |
| **建筑外饰 / 园林**（屋瓦、砖、园林石）| 🟡 中 | PolyHaven 部分 + 自建 |
