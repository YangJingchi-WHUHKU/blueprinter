## 怎么写调研文档

最简模板：

```markdown
# {主题}
> 作者 / 日期 / 背景一句话

## 1. 问题陈述
## 2. 候选方案
## 3. 实测对比 (表格)
## 4. 推荐 + 理由
## 5. 配套 PoC 代码位置
```

不要只给结论——**给数据 + 给可复现 PoC**。被其他人质疑时，你要能让他在自己电脑上跑一遍。

## 不该放这里的东西

- ✋ **进度跟踪 / 任务计划**（`*_progress.md` `*_task_plan.md`）→ 留本地 / Notion，不进仓库

- ✋ **会议纪要 / 灵感笔记**→ 不进仓库
- ✋ **个人学习笔记**→ 自己的 Notion / Obsidian
