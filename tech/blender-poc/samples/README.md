# ⚠️ 重要：这些样图不代表最终质量

> **这是"技术管线测试"的输出，不是"视觉效果 demo"。看着丑是正常的、是设计内的。**

## 为什么这么丑？

| PoC 用了什么 | 真实产品要用什么 |
|---|---|
| cube 拼"沙发"（就是个方块）| PolyHaven / BlenderKit 真实沙发 GLB 模型 |
| 平涂材质（一种颜色）| PBR 材质球 + 凹凸 + 漫反射贴图 |
| 1 个 area light + procedural 天空 | 真正的室内 HDRI（如 `quattro_canti_4k.exr`）|
| 默认相机参数 | 焦距/景深/曝光精调 |
| 0 后期 | 颜色分级 + LUT + 暗角 + 颗粒 |
| 0 资产库 | 30-50 件高质量预置家具/灯具/装饰 |

**这些样图只证明了一件事：bpy 程序化建模 + Cycles/EEVEE 渲染 + 360° 全景导出 管线可以跑通。**

## 真正的视觉质量靠这些（V2 待做）

1. ⏳ HDRI 环境贴图库（10-20 个室内 HDR）
2. ⏳ 真实家具模型库（50 件起步）
3. ⏳ 自动化决策智能层（光照 / 摄像机 / 后期 / 摆放）
4. ⏳ 风格 LUT 库（日式 / 北欧 / 工业风等 5-8 个）

完成这些后，目标是出图被评"和效果图公司一个水准"。**当前是 30 分，目标是 90 分。**
