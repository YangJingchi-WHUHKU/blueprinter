# 家装设计 Prompt 示例

这些 prompt 从真实用户视角出发，适合输入给室内设计生成、Blender 场景生成或家装方案规划系统。每条重点描述生活方式、风格、预算感、材质偏好和限制条件，不指定具体家具陈列位置。

## 1. 小户型整屋改造

**条目类型：小户型 / 收纳优先 / 现代简洁**

```text
我家是一个小户型，希望整体看起来干净、显大、收纳充足。风格偏现代简洁，不想要太复杂的装饰，也不喜欢厚重的家具。希望空间明亮，颜色以白色、浅木色、浅灰为主，整体要温暖但不要太奶油风。需要兼顾日常居住、偶尔朋友来访和基础办公。请帮我生成一个整体协调、空间利用率高、不显拥挤的家装设计方案。
```

## 2. 新婚夫妻客餐厅

**条目类型：年轻家庭 / 客餐厅 / 温暖自然**

```text
我们是一对新婚夫妻，希望客餐厅有温暖、放松、有生活感的氛围。喜欢现代自然风，材质上偏好木质、布艺、亚麻和少量黑色金属，不喜欢冷冰冰的样板间效果。希望空间适合两个人日常吃饭、看电影、聊天，也能招待三五个朋友。整体色彩希望是暖灰、胡桃木、米白和一点绿色点缀，灯光要柔和、有层次。
```

## 3. 有孩子的家庭客厅

**条目类型：亲子家庭 / 安全耐用 / 易清洁**

```text
家里有一个小孩，希望客厅既好看又适合孩子活动。风格希望是现代温馨，不要太锋利、太脆弱或太难打理的设计。材质需要耐磨、易清洁，颜色可以温暖一些，但不要过于花哨。希望有足够的活动空间、收纳玩具的地方，以及大人休息看电视的舒适感。整体要安全、实用、整洁。
```

## 4. 独居青年卧室

**条目类型：独居 / 卧室 / 情绪氛围**

```text
我是一个人住，希望卧室不只是睡觉的地方，也能让我下班后放松下来。喜欢安静、有包裹感、偏高级一点的氛围，不想要太甜、太网红的设计。颜色希望是深一点的暖灰、木色、黑色或低饱和蓝绿色。灯光要适合睡前阅读和夜间放松，整体感觉要干净、克制、有质感。
```

## 5. 居家办公书房

**条目类型：书房 / 长时间办公 / 专业稳定**

```text
我经常在家办公，需要一个能长时间专注工作的书房。希望风格偏现代专业，但不要像办公室那么冷。需要考虑电脑设备、书籍、文件、线缆管理和背景墙效果，因为我经常开视频会议。颜色希望以深木色、暖灰、黑色金属为主，可以有一点蓝色或绿色点缀。整体要安静、稳定、整洁，并且有足够的收纳。
```

## 6. 老人友好卧室

**条目类型：适老化 / 卧室 / 安全舒适**

```text
这是给老人住的卧室，希望设计安全、舒适、方便行动。风格不用太时髦，重点是温暖、明亮、耐看。希望减少复杂装饰和容易磕碰的设计，材质要防滑、好清洁，灯光要柔和但足够亮。颜色可以用浅木色、米色、暖灰，不要太暗。整体希望让老人住起来安心、方便、有家的感觉。
```

## 7. 宠物家庭客厅

**条目类型：宠物家庭 / 客厅 / 耐用易维护**

```text
家里有猫，希望客厅设计既好看又适合宠物生活。家具和材质需要耐抓、耐脏、方便清洁，不希望满屋都是宠物用品的感觉。风格偏现代自然，可以有木质、布艺、藤编或低饱和色彩。希望空间里能自然融入猫活动、休息和收纳的需求，同时保持整体整洁、有设计感。
```

## 8. 精装房软装升级

**条目类型：精装房 / 软装改造 / 低施工**

```text
我家是开发商精装房，不想大拆大改，主要希望通过软装、灯光、家具和局部墙面来提升质感。现在空间比较普通，有点样板间感，希望改成更温暖、更有个性的现代家居风格。预算希望控制，不做复杂施工。颜色希望比现在更柔和，材质上希望增加木质、布艺、装饰画和氛围灯，让整体更像真正有人生活的家。
```

## 9. 民宿风卧室

**条目类型：民宿 / 卧室 / 拍照友好**

```text
我想做一个适合短租民宿的卧室，希望第一眼有记忆点，但不要过度网红。风格可以偏侘寂、自然、复古或轻度度假感，整体要舒适、干净、容易维护。希望材质有层次，比如木质、亚麻、微水泥、藤编或陶土色元素。需要适合拍照，也要让住客真正觉得舒服。避免太复杂、太难清洁或太容易损坏的设计。
```

## 10. 厨餐一体空间

**条目类型：厨房 / 餐厅 / 实用高效**

```text
我希望厨房和餐厅是一个更开放、更适合日常使用的空间。平时会做饭，希望操作方便、台面好清洁、收纳充足，同时吃饭区域不要太正式。风格偏现代简洁，可以有浅木色、白色、灰色石材和少量金属元素。希望整体看起来清爽、明亮、有秩序，不要过度装饰，也不要像商业厨房一样冷硬。
```

## 11. 高级感客厅

**条目类型：客厅 / 质感优先 / 克制高级**

```text
我希望客厅看起来有高级感，但不是豪华酒店风，也不想要金色、大理石堆满的感觉。更喜欢克制、安静、有品质的现代风格。材质可以用深木色、皮革、织物、石材、金属和柔和灯光，颜色以暖灰、米色、深棕、黑色为主。空间要显得稳重、有层次，适合日常生活，也适合接待客人。
```

## 12. 奶油风但不廉价

**条目类型：全屋风格 / 奶油风 / 质感控制**

```text
我喜欢奶油风，但不希望做成廉价、全白、没有层次的效果。希望整体柔和、温暖、干净，但要有材质对比和细节。颜色可以是奶油白、浅咖、米灰、浅木色，适当加入一点深色或金属来压住空间。家具线条可以圆润一些，但不要过度可爱。整体要舒服、耐看、有质感。
```
